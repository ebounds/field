About the excerpts

The film uses excerpts from longer conversations about creative work, diagram design, and scientific evidence. The Field requests and scope responses were authored for the film. Each field was generated using Field’s reference renderer from a reading of the conversation at the selected point.

Field expresses the model’s accumulated stance. It makes no claim to directly measure hidden state or answer quality.

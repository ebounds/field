The field shown is the one the assistant drew inside the conversation, never a new interpretation, and each entry records the model and the Field version that drew it. The turn summaries were written afterward and reviewed by the person in the exchange. A marker shows where the field was drawn, so you can see which turns it could hold and which came after.
